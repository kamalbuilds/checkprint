Percentiles over the 100ms sample stream, not min and max. A single 100ms spike is not a delivery problem and sending an operator to it wastes their afternoon.

What the agent asked ClickHouse

A google.adk LlmAgent holds the official mcp-clickhouse server as an McpToolset and chooses its own queries: it lists tables, learns the schema, compares this title against the catalog baseline, then drills into the 100ms samples only when the numbers warrant it. raw mcp transcript
Checkprint measures features from the archive.org feature_films collection against EBU R128. Frames are extracted on demand with ffmpeg from the published file and cached on disk. Loudness telemetry is stored in ClickHouse at one sample every 100ms and read back through the official mcp-clickhouse MCP server.
